# Imagens do site

Todas as imagens ficam nesta pasta. Os nomes indicam o conteúdo, e uma mesma imagem pode ser reutilizada em várias seções sem criar cópias.

- `frutas-frescas.jpg`: hero, empresa e campanha.
- `frutas-citricas.jpg`, `bebida-com-frutas.jpg`, `banana.jpg`: galeria.
- `goiaba.jpg`, `abacaxi.jpg`, `maracuja.jpg`, `manga.jpg`: produtos.
- `polpa-maracuja.png` e `polpa-maracuja.webp`: embalagem da polpa.
- `favicon.svg`: ícone do site.

Para substituir uma foto, troque o arquivo mantendo seu nome ou atualize o caminho correspondente em `index.html` ou `css/`.
